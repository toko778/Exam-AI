# AI — ქართული საკონტაქტო გვერდი

ხელოვნური ინტელექტის ხელსაწყოების პრაქტიკული გამოყენების საგამოცდო დავალება. სამუშაო ფარგლებია ეს `AI` საქაღალდე; Holliday Planner-ის ფაილები არ შეცვლილა.

## შედეგი

მომზადებულია პერსონალური ქართული HTML/CSS გვერდი მომხმარებლის მოწოდებული სახელით, ელფოსტით, ტელეფონითა და GitHub ბმულით. გვერდზე გამოიყენება ქართული ადგილობრივი შრიფტი, რეალური mailto/tel ბმულები, მისამართის კოპირების ღილაკი, გენერირებული ილუსტრაცია და SVG ხატულები.

ეს არის Holliday Planner-ისგან დამოუკიდებელი პროექტი. გვერდი იხსნება ლოკალურად; ამ ეტაპზე ჰოსტინგზე გამოქვეყნება არ შესრულებულა.

## გაშვება

`index.html` პირდაპირ ბრაუზერშიც იხსნება. ლოკალური სერვერისთვის, ამ საქაღალდეში:

```powershell
npm.cmd run dev
```

მისამართია `http://127.0.0.1:5180`. სერვერი ჩერდება `Ctrl+C`-ით.

```powershell
npm.cmd run check
npm.cmd run build
```

პროექტს გარე JavaScript დამოკიდებულებები არ სჭირდება. `build` ქმნის მხოლოდ გამოსაქვეყნებელ ფაილებს `dist/`-ში. prompts, API-ის მტკიცებულებები და გენერაციის ხელსაწყო გამოქვეყნებულ სტატიკურ ფაილებში არ ხვდება.

მონაცემების შესაცვლელად განაახლე `profile.json`, შემდეგ გაუშვი `node tools/apply-profile.mjs` და build. ელფოსტისა და ტელეფონის აპის გახსნა რეალურ გაგზავნას/ზარს თავისით არ ასრულებს.

## შემოწმება

2026-11-12-ზე გავლილია 11/11 სტატიკური შემოწმება და build. ბრაუზერში შემოწმდა 1280, 390 და 320 px სიგანეები, სურათები, კლავიატურის ფოკუსი და შიდა ბმულები. შენახულია 5 სქრინშოტი. კოპირების ღილაკმა აჩვენა წარმატების შეტყობინება, თუმცა clipboard-ის მკითხველმა ცარიელი მნიშვნელობა დააბრუნა; შიგთავსის დამოუკიდებელი თანხვედრა დადასტურებულად არ ინიშნება. შედეგებია `evidence/checks/browser-check.json`-ში.

## ფაილები

```text
index.html, styles.css, contact.js   საბოლოო გვერდი
profile.json                        მოწოდებული საკონტაქტო მონაცემები
assets/contact-paper.png            ImageGen ილუსტრაცია
assets/icons/                       Groq-ის სამი SVG
assets/fonts/                       Noto Sans Georgian და OFL ლიცენზია
prompts/                            შენახული ზუსტი AI მითითებები
evidence/code/                      Codex და Groq კოდის ვარიანტები
evidence/groq/                      რეალური API პასუხი და გამოყენების მონაცემები
evidence/imagegen/                  ილუსტრაციის წარმომავლობა
evidence/checks/                    გავლილი შემოწმებები და შეზღუდვები
Screenshots/                        მხოლოდ ხუთი რეალური სქრინშოტი
docs/                               მოთხოვნები, შეფასება და ხელსაწყოების აღწერა
tools/                              გაშვება, შემოწმება და აწყობა
```

Groq-ის გასაღები ფაილებში არ ინახება და ბრაუზერში არ იგზავნება. იგი ამ დავალებაში მხოლოდ შექმნის ხელსაწყოდ გამოიყენება. ახალი გენერაციის ხელსაწყო გასაღებს დამალული stdin-ით ითხოვს.
