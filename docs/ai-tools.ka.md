Groq-ის რეალური პასუხის მოდელია `qwen/qwen3.8-27b`. მოთხოვნის ID და ტოკენების მოხმარება შენახულია პასუხის მტკიცებულებაში. პასუხს მოხმარდა 2638 ტოკენი: 389 input და 2249 output. ეს ახალი HTML/CSS გენერაციაა და არა Holliday Planner-ის API პასუხის ხელახალი გამოყენება.

## მინიმუმ ორი ხელსაწყოს გაერთიანება

კოდისთვის გამოყენებულია Codex და Groq. საბოლოო ვერსიაში გაერთიანებულია Codex-ის `dl/dt/dd` საკონტაქტო სემანტიკა და Groq-ის flex განლაგების, 44px სამიზნის, `min-width: 0` და გრძელი მისამართის გადატანის მიდგომა. ფერები, კლავიატურის ფოკუსი და responsive განლაგება საბოლოოდ გადამუშავდა.

გრაფიკისთვის გამოყენებულია ImageGen და Groq. ImageGen ქმნის raster PNG ილუსტრაციას; Groq-ის ტექსტური მოდელი ქმნის ნამდვილ SVG ვექტორულ კოდს. ელფოსტის, ტელეფონისა და ისრის სამივე SVG შემოწმდა აკრძალულ script/event/external reference ელემენტებზე.

ამ ჩანაწერში ხელსაწყოებს განსხვავებული როლები აქვთ. Groq-ის SVG გენერაციას ფოტო გენერაციად არ ვასაღებთ. შრიფტი მესამე მხარის ლიცენზირებული აქტივია და AI-ით შექმნილ გრაფიკად არ ითვლება.

## Prompt-ის სტრუქტურა

Codex-ის მითითება ადგენს ამოცანას, შესატან მონაცემებს, გამომავალ ფაილებს, დიზაინის შეზღუდვებსა და შემოწმების კრიტერიუმებს. Groq-ის prompt დამატებით ითხოვს list/card/table შედარებას, კონკრეტულ ქართულ labels-სა და ზუსტ JSON სქემას. ImageGen-ის მითითება განსაზღვრავს თემას, მასალას, ფერებსა და აკრძალულ ელემენტებს.

პირადი საკონტაქტო მონაცემები გენერაციის prompt-ებში არ გადაცემულა: იქ გამოიყენება NAME/EMAIL/PHONE ნიშნები. ნამდვილი მონაცემები მომხმარებლისგან მიღების შემდეგ ლოკალურად ჩაისვა HTML-ში.

## გადამუშავება

Groq-ის პასუხში პირადი გვერდის ტექსტი შეიცავდა მრავლობით `დაგვიკავშირდი` ფორმას. საბოლოოდ გამოყენებულია `დამიკავშირდი` და `მომწერე`. ღია ოქროსფერი მცირე წარწერები შეიცვალა უფრო მუქი ტონით. რაოდენობრივი კონტრასტის შედეგები ინახება `evidence/checks/static-check.json`-ში.

წყაროები: [Groq API](https://console.groq.com/docs/api-reference), [სტრუქტურირებული პასუხები](https://console.groq.com/docs/structured-outputs), [Qwen მოდელი](https://console.groq.com/docs/model/qwen/qwen3.8-27b). მხარდაჭერა გადამოწმებულია 2026-11-11-ზე.
