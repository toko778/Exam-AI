# Codex-ის სამუშაო prompt

შექმენი ერთი ქართული საკონტაქტო HTML5 გვერდი საგამოცდო დავალებისთვის. გვერდზე იყოს გამოსაჩენი სახელი, ელფოსტა, ტელეფონი და სოციალური ბმულები. შექმენი მარტივი, გასაგები HTML/CSS; framework და მძიმე ბიბლიოთეკები არ გამოიყენო. პირველ ეტაპზე პირადი მონაცემები ჩაანაცვლე `NAME`, `EMAIL`, `PHONE` ნიშნებით — საბოლოო მონაცემებს მომხმარებელი მოგვაწვდის.

ჯერ შეადგინე დამოუკიდებელი მოკლე HTML/CSS ვარიანტი და შეინახე მტკიცებულებად. შემდეგ შეადარე Groq-ის დამოუკიდებელ პასუხს და საბოლოო გვერდში გააერთიანე რეალურად გამოყენებული ნაწილები.

დიზაინი: ქართული წაკითხვადი ტექსტი; ღია ქაღალდისფერი ფონი; მუქი ლურჯი ძირითადი ფერი; ზომიერი ოქროსფერი აქცენტი; საკონტაქტო ინფორმაცია სემანტიკურ ბარათში. გამოიყენე CSS ცვლადები, clamp ტიპოგრაფია, მინიმუმ 44px მოქმედების სამიზნეები, ხილული focus-visible, 320px-მდე ადაპტაცია და prefers-reduced-motion. ტექსტი დარჩეს ნამდვილ HTML-ად. გენერირებული ილუსტრაცია და SVG ხატულები დამოუკიდებელი აქტივებია.

ელფოსტისთვის mailto და ტელეფონისთვის tel ბმულები გამოიყენე მხოლოდ მომხმარებლის რეალური მნიშვნელობების დამატების შემდეგ. სოციალური ბმულები იყოს მომხმარებლის მოწოდებული მისამართები. წერილის გაგზავნის ან სხვა გარე მოქმედების წარმატება არ გაითამაშო.
