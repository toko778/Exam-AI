საწყისი ვარიანტების NAME/EMAIL/PHONE ნიშნები გენერაციის ეტაპის ნაწილია; საბოლოო გვერდზე მომხმარებლის მოწოდებული მონაცემებია. ეს ორი კადრი ასახავს HTML/CSS-ის შედეგებს და არ წარმოადგენს AI ჩატის ინტერფეისის სქრინშოტებს.

Prompt-ები ინახება `prompts/`-ში. API გასაღებები მტკიცებულებებში არ ინახება. კოპირების მოქმედებამ აჩვენა წარმატების ტექსტი; ბრაუზერის clipboard-ის მკითხველმა ცარიელი მნიშვნელობა დააბრუნა, ამიტომ შიგთავსის დამოუკიდებელი თანხვედრა დადასტურებულად არ ინიშნება.
